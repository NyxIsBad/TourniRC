TourniRC Help

TourniRC is an IRC client for osu. It's different from apl (not lazer), wyref (less automation), while trying to be more modern than c4o and brigitta. Originally made for personal use.

Getting started

Use your osu! username and IRC password from the Legacy API section of your osu! account settings. The saved password is kept in cfg/login.ini.

You can change your theme anytime top right.

Rooms and tabs

Open channels with /query #channel or users with /query username. (can also press the Add Channel button in actions) Double-click a tab to rename it locally. Drag tabs to reorder them.

Recent Rooms stores only MP rooms and channels. Its limit is configured in Settings.

Connection

TourniRC reconnects to Bancho and rejoins room channels while its backend remains open. If the backend itself dies/restarts, in-memory tabs and history are lost.

IRC has no message acknowledgement, so messages sent by you immediately before a disconnect may not actually sent. Because there's no way to see if Bancho actually got them, you'll have to resend them maybe

Local commands

  • /query <room or user>
  • /part [room]
  • /clear
  • /timer [seconds]
  • /matchtimer [seconds]
  • /savelog [room]

There are aliases for these, which you can find in Settings, and you can change; but command aliases can only point to these default local commands. You can define new command macros (which send things in chat), along with changing the existing hotkeys in settings. New macros can be also optionally added to the Action bar. They can only be run by you, and you can define them into slash commands too.

Blocking

The PM block list suppresses blocked private messages, tabs, unread indicators, and sounds. A red notice tells you if they message you

Sound alerts

Upload MP3, WAV, or OGG files with limit 5mb, or use the original audio samples (ripped from Brigitta). Triggers can use literal text or regex (it's pythex), sender filters, case sensitivity, and channel scope. You gotta add these yourself

Referee controls

Match controls send the command displayed by their title. Player and match information comes from BanchoBot and may remain unknown until you request !mp settings, so generally run it often
